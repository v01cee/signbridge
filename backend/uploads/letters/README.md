# Видео для дактильного алфавита

Скидывай сюда файлы **по одному на букву**:

```
а.mp4
б.mp4
в.mp4
...
я.mp4
```

## Правила

- **Имя файла = буква** (маленькая) + расширение
- Поддерживаемые форматы:
  - **Видео**: `.mp4`, `.webm`, `.mov` (рекомендуется mp4, ~3-5 МБ, без звука или с muted)
  - **Изображения**: `.jpg`, `.png`, `.gif`, `.webp`
- Какие буквы найдутся — те и подключатся
- Какие не найдутся — fallback на общую таблицу Wikimedia

## После добавления

1. Запушить (или скопировать) папку на сервер
2. Перезапустить seed:
   ```bash
   docker exec signbridge-backend-1 python scripts/seed.py
   ```
3. Видео автоматически попадут в карточки + детальную страницу
   и будут зацикленно проигрываться без звука.
